# 方位仪

面向 iPhone Safari 的定位与指南针网页应用。静态文件可直接部署到 GitHub Pages，无需构建或安装依赖。

## 在 iPhone 上使用

1. 用 Safari 打开 GitHub Pages 的 HTTPS 地址。
2. 在 Safari 的分享菜单中选「添加到主屏幕」。若有「作为网页 App 打开」选项，请保持开启。
3. 联网从主屏幕打开一次，等顶部显示「离线缓存就绪」。
4. 点「开始定位」并授权。点「启用指南针」并授权，将手机平放。

## 数据和离线

- 定位卡显示经纬度、设备提供的海拔和精度、速度、移动方向及读数时间。经纬度采用浏览器定位 API 的 WGS 84 坐标。海拔这一栏保留设备直接提供的数值，未进行高程基准转换。设备缺少字段时显示「—」。
- 指南针使用 Safari 提供的机身朝向。定位栏独立显示移动方向，静止时可能没有移动方向读数。
- Service Worker 缓存页面、脚本、样式和图标。应用直接读取系统数据，离线时能否获得新的定位及海拔取决于设备与现场条件。
- 坐标只在当前页面内存中使用，不会上传或写入浏览器存储。停止定位后可复制当次会话的最后读数。

## 部署

将这个目录内的文件放在 GitHub 仓库的 `main` 分支根目录。在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**，然后选择 **main → /(root)**，保存后访问 GitHub 给出的 HTTPS 地址。所有资源都使用相对路径，也支持项目仓库的子路径。

本地可在此目录运行 `python3 -m http.server 8000 --bind 127.0.0.1`，访问 `http://localhost:8000/`。更新页面资源时同步递增 `sw.js` 中的缓存版本。旧窗口关闭后，已下载的新版本会在下一次打开时接管。
